Trading Performance & Risk Analytics Dashboard

Using Power BI to transform historical trading records into meaningful performance metrics, profitability analysis, and visual insights.

Project Overview

This project focuses on analysing historical trading activity through an interactive Power BI dashboard. The aim is to make trading performance easier to evaluate by consolidating key metrics and visualising profitability across time and instruments.

The dataset contains trade dates, instruments, trade direction, volume, entry and exit prices, and recorded profit or loss. Power Query was used to prepare the data, while DAX measures were developed to calculate performance indicators.

Dashboard Preview

The dashboard brings together trading performance indicators and visualisations in one report.

Trading Performance & Risk Analytics dashboard built in Power BI.

Key Performance Indicators

  • Total number of trades
  • Win rate and winning versus losing trades
  • Average profit on winning trades
  • Average loss on losing trades
  • Profit factor
  • Total net profit or loss

Visual Analysis

  • Daily Trading P/L: Examines recorded profit and loss by trade date.
  • Cumulative Trading P/L: Tracks how profit and loss accumulate over time.
  • Winning vs Losing Trades: Compares the number of profitable and unprofitable trades.
  • Net P/L by Instrument: Compares results for XAUUSD and BTCUSD.

Tools & Technologies

  • Power BI
  • Power Query
  • DAX
  • Excel
  • Data Cleaning
  • Data Visualisation

Skills Demonstrated

Data preparation, data transformation, analytical calculations, KPI development, data visualisation, and performance reporting.

Project Reflection

This project provided practical experience converting transactional data into a structured analytical report. It also demonstrated how calculated metrics and visualisations can help users examine performance patterns and identify areas for further investigation.
