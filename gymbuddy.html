GYM BUDDY APP

Gym Buddy is a mobile application designed to help gym members connect through guest and buddy passes while making it easier to create, manage, and join gym sessions.

My Contribution

I primarily worked on the backend of the application, including application logic, Firebase Firestore integration, user data management, session management, and the request and approval functionality between users.

The Application

Authentication

Users can securely log in to their existing account or create a new account through the registration page. New users can register an account to access the application.

PassHolder Page

The PassHolders account is for members of the gym that want to invite a buddy to the gym. The PassHolder can create sessions that their buddies can request to join. The PassHolder can also edit the sessions they had created as preferred.

Non-PassHolder Page

This page displays the sessions created by the PassHolder and allows the NonPassHolder to request to join a preferred session. This page provides the status of a request sent to join a session. Once the PassHolder approves, the status changes.
